# 실제 의류·잡화 로고 적용 사례 학습 (2026-11-20 조사)

`config/logo_placement_library.yaml`의 근거 자료입니다. 원문 단위는 inch이고, 괄호 안 cm는 환산값입니다. 공급사마다 수치가 달라 범위로 적었습니다. **추정** 표시는 검증하지 못한 값입니다.

## A. 업계 표준 위치

### 상의
| 위치 | 기준점 규칙 | 로고 폭 | 기법 |
|---|---|---|---|
| 왼쪽 가슴 | 로고 상단이 칼라 아래 3–4in(7.5–10cm), 센터라인에서 3–6in(7.5–15cm). Vistaprint는 HPS 기준 7–9in. 여성용은 더 높게 | 3–4in(7.5–10cm). 후디는 4–4.5in | 자수, 스크린, 실리콘, 패치 |
| 센터 가슴 | 칼라 아래 3–4in | 5–7in(13–18cm) | 스크린, DTF, 자수 |
| 상단 등 | 뒤 칼라 아래 약 4in | 8–12in | 스크린, 자수 |
| 백넥 | 칼라 봉제선 아래 1–2in | 2–3in(5–7.5cm) | 스크린, 자수, 우븐 |
| 내부 넥 프린트 | 안쪽 뒷목 중앙 | 최대 약 7cm | 열전사 |
| 내부 넥 우븐 라벨 | 넥 봉제선 | 4×2–5×2.5cm | 우븐 |
| 소매 상단 | 팔 중앙. 어깨 봉제선은 피함 | 2–3in. 세로형은 최대 2.5–3×12–14in | 스크린, 자수, DTF |
| 헴·사이드 플래그 | 옆선이나 밑단에 접어 봉제 | 플래그 1×1in. 사이드심 0.5×1.5–0.75×2in | 우븐 |
| 후드 옆면 | 후드 좌·우 측면 | 최대 5×5in | 스크린, 자수 |
| 지퍼 풀러 | 탭 전체(**추정**) | 1–2cm | 러버, 레이저 |

### 하의, 모자, 가방, 텀블러
| 상품 | 위치와 크기 |
|---|---|
| 하의 | 왼쪽 엉덩이·허벅지: 허리밴드 아래 약 8in(20cm), 옆선 1in 안쪽, 최대 5×5in. 허리밴드 뒤는 작은 마크용(lululemon Align 확인, 크기는 **추정** 3–6cm). 레깅스 발목은 폭 2in 이하 |
| 캡 | 정면: 폭 4–5in, 높이 2.25in 이하(트러커 5×2in). 측면: 2–2.5×1–1.25in(최대 2.75×1.75in). 뒷면 클로저 위: 2.25–3×0.75–1in. 스트랩: 2.5×0.375in |
| 비니 | 커프 패치 PU 실측 5×3cm |
| 가방 | 정면 4×3in부터 2×2in까지. 봉제선과 지퍼가 쓸 수 있는 면적을 줄임 |
| 텀블러(40oz) | 몸통 1.5W×3H in. 프린트 영역 4H×3.5in. Stanley 커스텀은 로고 반대면에 1.5in 레이저 각인 |

## B. 기법별 최소 규격과 실사감 단서
| 기법 | 최소 규격 | 실사감 단서 |
|---|---|---|
| 평자수 | 글자 높이 6.35mm, 선 1.27mm 이상 | 새틴 광택 방향, 주변 퍼커링, 가장자리 실 요철 |
| 3D 퍼프 | 선 5–12.7mm, 글자 11mm 이상 | 볼록한 높이, 둥근 모서리, 측면 그림자 |
| 톤온톤 자수 | 평자수와 같음 | 광택과 요철만으로 보임 |
| 스크린 프린트 | 선 0.35mm, 틈 1mm 이상 | 잉크가 원단 결에 묻힘 |
| 열전사·반사 | 선 0.8–1mm | 필름층, 플래시에 은회색 |
| 실리콘 | 1.2mm 이상 | 고무 반광, 또렷한 경계 |
| 우븐 라벨 | 글자 1.5–2mm, 요소 0.2mm | 직조 결, 접힘, 테두리 박음질 |
| 가죽 디보스 | 단순한 형태만 | 음각이 진해짐, 가죽 결, 모서리 박음질 |
| 레이저 각인 | 디보스보다 세밀함 | 도장층이 벗겨져 금속 노출 |

## D. 슬로건 배치 관행
백넥은 폭 5–7.5cm. 소매는 2.5×1in, 세로형은 최대 14in. 플래그 라벨은 1×1in. 내부 넥은 7cm 이내. 캡 스트랩은 2.5×0.375in. 텀블러는 측면 세로 1.5×3in. 행택과 패키지가 가장 일반적인 위치입니다(**추정**).
